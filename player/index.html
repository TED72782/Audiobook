Audiobook Player

A private repository needs a token. To make one that can only read this repository:
  1. Open GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories, and pick the audiobook repository.
  3. Permissions → Repository → Contents: Read-only.
  4. Generate, copy the token, and paste it above.
The token is kept only in this browser's storage and is sent only to api.github.com.
